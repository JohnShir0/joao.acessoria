# Site do João Vitor – Estratégia & Liberdade Financeira

Este é um site estático criado com HTML, CSS e Tailwind, ideal para publicação via GitHub Pages.

### ✅ Como publicar:
1. Crie um repositório no GitHub.
2. Faça upload dos arquivos deste ZIP.
3. Vá em `Settings > Pages`, selecione a branch `main` e a pasta `/ (root)`.
4. Acesse seu site em `https://SEU_USUARIO.github.io/NOME_DO_REPO`.
